# @sonae/engine (owner: P1)

The 48-hour planner and the Summer 2026 Replay. Pure TypeScript, no I/O, so it runs in the browser, on the phone, on the server and in tests.

- `plan(input: PlanInput): Plan` builds the pump schedule, tank curve, turns, alerts and KPIs.
- `replay(...)` replays a season with and without Sonae.

Run the tests with `npm test` from the repo root.
